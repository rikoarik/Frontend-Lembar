## Cara kerja

- **Satu task = satu concern = satu commit.** Tidak menggabungkan i18n dengan fitur, atau audit dengan perbaikan.
- Setiap task punya: ID, scope, bukti selesai (DoD), role penanggung jawab.
- Task dikerjakan sesuai role: `lembar-frontend`, `lembar-backend`, `lembar-qa`, `lembar-reviewer`, `lembar-devops`, `lembar-edu`.
- Urutan mengikuti gelombang (W1 → W5). Task dalam gelombang yang sama boleh paralel **hanya jika** tidak menyentuh file yang sama.
- `BLOCKED` = menunggu keputusan owner atau task lain. Jangan dipaksakan.

### Aturan commit (dari TASK-REGISTRY)

- `direct_main_merge_push: forbidden` — jangan push langsung ke `main`
- `force_push: forbidden`
- `api_endpoint_invention: forbidden` — jangan mengarang endpoint BE
- Jalur: task branch → `ao/frontend-integration` → `dev`

### Gate teknis wajib per task

```bash
cd ~/Projects/Frontend-Lembar
pnpm tsc --noEmit          # 0 error
pnpm lint                  # 0 error (eslint wajib ignore .worktrees/**)
pnpm test                  # semua hijau
pnpm build                 # sukses
```

Untuk task yang menyentuh route: verifikasi `.next/BUILD_ID` berubah, lalu `pm2 restart lembar-frontend --update-env`, lalu smoke HTTP.

### OWNER-01 · Keputusan model "Materi"

**Blocker untuk:** FE-MAT-01, FE-MAT-02, FE-MAT-03, BE-MAT-01

Pertanyaan yang harus dijawab:

1. Guru boleh **membuat** materi sendiri, atau hanya memilih dari katalog?

5. Lampiran materi (gambar/PDF) **terpisah** dari "PDF saya" di flow generate, atau memakai yang sama?

**DoD:** kelima pertanyaan terjawab dan tercatat di `docs/product/DECISIONS.md`.

## W1 — Audit mendalam (bisa jalan sekarang)

### FE-AUD-01 · Audit flow live: auth + onboarding

**Role:** `lembar-qa` · **Prioritas:** P0

Scope: `/masuk`, `/daftar`, `/lupa-sandi`, `/reset-sandi`, `/undangan/[token]`, `/trial/claim`, `/auth/callback`, `/app/onboarding`, `/app/workspace-switcher`.

Yang diperiksa:

- login/register/logout round-trip via BFF, cookie `lembar_token` + `lembar_session`
- redirect per role: `superadmin` → `/ops`, `school_admin` → `/school`, else → `/app`
- recovery & reset password end-to-end
- undangan sekolah: accept, membership muncul, tanpa klaim email terkirim kalau memang tidak
- Google OAuth: URL consent → `/auth/callback?code=` → cookie
- state: loading, error, invalid token, token kedaluwarsa

**DoD:** laporan per route dengan HTTP code + screenshot + daftar bug bernomor. Pakai akun test terpisah (seed DB), bukan akun asli.

### FE-AUD-02 · Audit flow live: generate → job → review → output

**Role:** `lembar-qa` · **Prioritas:** P0

Scope: `/app/generate`, `/app/jobs/[jobId]`, `/app/riwayat`, `/app/review/[assessmentId]`, `/app/review/[assessmentId]/finalize`, `/app/output/[assessmentId]`, `/app/output/[assessmentId]/print`, `/app/output/[assessmentId]/results`.

Yang diperiksa:

- ketiga `sourceMode`: `katalog`, `pdf`, `katalog+pdf`
- dependency berantai: ganti kurikulum → kelas & mapel & materi direset (L299–310)
- materi dari katalog benar-benar terkirim ke BE (`materialIds`)
- upload PDF: progress, gagal, file terlalu besar, tipe salah
- job progress: stage nyata, bukan progress palsu; refresh-safe
- review: quick vs detail, bulk accept, filter, keyboard nav
- finalize: blocker tampil, tidak bisa finalize kalau ada blocker
- output: preview, print, unduh, CSV hasil
- state: empty, loading, error, source insufficient, job failed, retry

**DoD:** laporan per route + bukti baris DB Postgres sebelum/sesudah generate.

### FE-I18N-03 · Namespace `generate` + `jobs` + `review` + `output`

**Role:** `lembar-frontend` · **Prioritas:** P0

Cakupan: `src/features/generate` (termasuk `LABELS`), `src/features/jobs`, `src/features/review`, `src/features/output`, `src/features/history`, `src/features/library`.

Perhatian: `LABELS: Record<CompositionFieldKey, string>` harus tetap exhaustive. Kalau label dipindah ke i18n, ubah tipe jadi fungsi `(t) => Record<...>` agar tidak kehilangan jaminan compile-time.

**DoD:** 4 namespace terisi; tidak ada string literal di keempat feature; `pnpm tsc --noEmit` bersih.
